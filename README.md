# Gerenciador de Agenda (Flask)

Sistema web para gerenciamento de contatos e usuários desenvolvido com Python e o framework Flask.

## Tecnologias Utilizadas
- **Backend:** Python 3.x e Flask.
- **Frontend:** Jinja2, HTML5 e CSS3.
- **Arquitetura:** Organização modular por Blueprints.

## Como Executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o projeto: `python microblog.py`
3. Acesse: `http://127.0.0.1:5000`
